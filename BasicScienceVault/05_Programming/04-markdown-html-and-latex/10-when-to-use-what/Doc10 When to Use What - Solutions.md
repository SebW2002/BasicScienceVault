# Doc10 When to Use What – Solutions

> Worksheet: [[Doc10 When to Use What - Worksheet]] · Theory: [[Doc10 When to Use What]] · Wrong? → [[Mistakes - Markdown HTML LaTeX]]

## Level 1
1. a) **Markdown** (Obsidian): fast, linkable, formulas render. b) **LaTeX**: numbering, cross-references, bibliography and typography at scale (Quarto book → LaTeX is an alternative). c) **HTML** (generated by MNE Report/Quarto/`publish`): figures plus folded details per subject, opens in any browser. d) **Markdown**: GitHub renders `README.md` automatically. e) **HTML** (+ JavaScript, e.g. Nilearn `view_img` or Plotly): interactivity needs a browser.
2. Markdown: + quick, plain text, portable / − limited layout, flavours differ. HTML: + layout, interactivity, media / − verbose by hand, weak print layout. LaTeX: + maths, typography, automatic numbering and references / − learning curve, compile errors.

## Level 2
3. Pandoc: `pandoc notes.md -o notes.pdf` (uses a LaTeX engine for PDF; `--pdf-engine=xelatex` for Unicode fonts).
4. Code execution (R, Python, Julia) with results embedded, cross-references for figures/tables/equations, project types (websites, books), many output formats and templates – all on top of Pandoc.
5. Pandoc doesn't understand wikilinks (`[[…]]`), embeds, callouts, `==highlights==` or Obsidian comments – they appear as raw text or vanish. Convert them (export plugin) or use standard Markdown; check that math and images (relative paths) work.

## Level 3
6. Write in Markdown/Quarto (with `[@citations]` and a shared `.bib`), render to `.docx` (optionally with a reference document for the journal's styles), let co-authors comment/track changes in Word, and transfer the changes back into the source (or switch to Word for the final round). Alternatively Overleaf/Google Docs if everyone agrees.
7. LaTeX **beamer** (or Quarto revealjs): equations typeset as in a paper; the same LaTeX equations, figures (PDF) and `.bib` can later be reused in the paper. Quarto can produce both slides and a manuscript from shared snippets.

## Level 4
8. Notes and reading summaries: **Markdown** in Obsidian (this vault, Zotero-linked citations). Analyses: scripts + **Quarto/Jupyter → HTML** reports for the lab, figures exported as PDF/SVG. Papers: journal template in **LaTeX** (Overleaf/VS Code) or Quarto → LaTeX/Word; methods text drafted in Markdown and converted with Pandoc. Thesis: **LaTeX** (university class) including the papers as chapters, with figures and tables generated from the analysis code. Flow: notes → drafts → papers → thesis, with shared `.bib`, notation macros and figure scripts.
9. Typical changes: replace wikilinks with plain text or Markdown links, turn callouts into normal blockquotes, embed images with `![](path)` instead of `![[…]]`, replace `$\lvert x\rvert$`-style table escapes if needed, and add a YAML header (title, author). Formulas in `$…$` and `$$…$$` usually convert unchanged.
