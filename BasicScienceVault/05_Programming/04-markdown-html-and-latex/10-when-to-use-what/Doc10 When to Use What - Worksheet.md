# Doc10 When to Use What – Worksheet

> Theory: [[Doc10 When to Use What]] · Solutions: [[Doc10 When to Use What - Solutions]] · Log mistakes in [[Mistakes - Markdown HTML LaTeX]]
> Answer on paper; try things out only for tasks marked 💻.

## Level 1 – Choose
1. Markdown, HTML or LaTeX (or a tool producing it)? Justify in one sentence each: a) lecture notes on the Nernst equation b) a 120-page thesis with 60 equations c) QC reports for 40 subjects d) a dataset README on GitHub e) an interactive 3-D brain plot for a lab website.
2. Name one strength and one weakness of each format.

## Level 2 – Converting
3. Which tool converts Markdown to LaTeX/PDF/Word? Write the command for Markdown → PDF.
4. What does Quarto add to Pandoc?
5. You wrote notes in Obsidian with wikilinks and callouts and want a PDF for your supervisor. What do you need to watch out for?

## Level 3 – Plan
6. Your co-authors only use Word, you prefer plain text. Describe a workflow that keeps both sides happy.
7. You must give a talk with many equations next week and might later turn it into a paper. Which format(s), and why?

## Level 4 – Neuro transfer
8. Design a document pipeline for a PhD project: notes, analysis reports, papers, thesis. Which formats and tools at which stage, and where does the content flow?
9. 💻 Take one of your Obsidian notes with formulas (e.g. [[Doc02 Math in Markdown]]), copy it, remove Obsidian-specific syntax, and convert it with `pandoc note.md -o note.pdf`. What had to be changed?
