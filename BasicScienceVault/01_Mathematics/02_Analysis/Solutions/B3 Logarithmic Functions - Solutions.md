# B3 Logarithmic Functions – Solutions

> Worksheet: [[B3 Logarithmic Functions - Worksheet]] · Theory: [[B3 Logarithmic Functions]] · Wrong? → [[Mistakes - Analysis]]

## Level 1
1. a) $2x - 4 > 0 \Rightarrow x > 2$ b) $x \neq 0$ c) all $x \in \mathbb R$ ($x^2 + 1 > 0$ always)
2. $x - 3 = 1 \Rightarrow x = 4$
3. $y = \ln(x+2) \Rightarrow e^y = x + 2 \Rightarrow f^{-1}(x) = e^x - 2$
4. $0 < x < 1$
5. Shift right by 1, up by 2. Asymptote $x = 1$.

## Level 2
6. $x = e^2$; $\;3x = 1 \Rightarrow x = \tfrac13$
7. $3x - x = 2x$
8. Domain: $x > 2$. $\ln(x(x-2)) = \ln 3 \Rightarrow x^2 - 2x - 3 = 0 \Rightarrow (x-3)(x+1) = 0$. Only $x = 3$ is in the domain.

## Level 3
9. $\ln y = \ln 5 - 0.2t$ → slope $-0.2$, intercept $\ln5$; $\tau = 1/0.2 = 5$.
10. $\log y = \log 3 + 2\log x$ → slope 2.
11. $\log y = \log 10 - \log x \Rightarrow y = \dfrac{10}{x}$
12. $x^{0.1}$ – every positive power eventually beats the logarithm (though only for very large $x$).

## Level 4
13. a) $k\ln(2I/I_0) - k\ln(I/I_0) = k\ln 2$ – independent of $I$. b) $2k\ln2 = k\ln4$ → factor 4.
14. $H = \tfrac12 \cdot 1 + \tfrac14 \cdot 2 + \tfrac14 \cdot 2 = 1.5$ bits ($-\log_2\tfrac12 = 1$, $-\log_2 \tfrac14 = 2$).
15. $4 = 10e^{-4/\tau} \Rightarrow \ln 0.4 = -4/\tau \Rightarrow \tau = \dfrac{4}{\ln 2.5} \approx \dfrac{4}{0.916} \approx 4.37\,\text{ms}$
