# B4 Trigonometric Functions – Solutions

> Worksheet: [[B4 Trigonometric Functions - Worksheet]] · Theory: [[B4 Trigonometric Functions]] · Wrong? → [[Mistakes - Analysis]]

## Level 1
1. $\tfrac12$; $\;\tfrac12$; $\;1$; $\;-1$; $\;-1$
2. $\frac\pi4$, $\frac{2\pi}3$, $\frac{3\pi}2$; $\;\frac{5\pi}6 \cdot \frac{180°}{\pi} = 150°$
3. a) $A = 3$, $T = \frac{2\pi}{2} = \pi$ b) $A = 2$ (sign = flip), $T = \frac{2\pi}{1/2} = 4\pi$ c) $A = 1$, $T = \frac1{10}\,\text{s} = 100\,\text{ms}$

## Level 2
4. $1 + \frac{\sin x}{\cos x}\cos x = 1 + \sin x$
5. $-\sin x$; $\;\sin x$
6. $\sin^2(-x) = (-\sin x)^2 = \sin^2 x$ → even. $\sin(-x)\cos(-x) = -\sin x\cos x$ → odd.
7. $\tfrac12\sin\frac\pi6 = \tfrac12\cdot\tfrac12 = \tfrac14$
8. $\sin(45° + 30°) = \frac{\sqrt2}2\cdot\frac{\sqrt3}2 + \frac{\sqrt2}2\cdot\frac12 = \dfrac{\sqrt6 + \sqrt2}{4}$

## Level 3
9. $x = \frac\pi6$ and $x = \pi - \frac\pi6 = \frac{5\pi}6$
10. $2x = \frac\pi2 + k\pi \Rightarrow x = \frac\pi4 + \frac{k\pi}2$ → $\frac\pi4, \frac{3\pi}4, \frac{5\pi}4, \frac{7\pi}4$
11. $\cos^2 x = \tfrac12 \Rightarrow \cos x = \pm\frac{\sqrt2}2$ → $x \in \{\frac\pi4, \frac{3\pi}4, \frac{5\pi}4, \frac{7\pi}4\}$ (same as 10, because $2\cos^2x - 1 = \cos 2x$!)

## Level 4
12. $y(t) = 5\sin(20\pi t)\,\mu\text{V}$, $T = 0.1\,\text{s}$
13. a) $60°$, $35\,\text{Hz}$ b) $60° + 180° = 240°$, $5\,\text{Hz}$ c) $\cos 90° = 0 \Rightarrow 20\,\text{Hz}$
14. $\Delta\varphi = 2\pi \cdot 8 \cdot \frac1{32} = \frac\pi2$ (a quarter cycle)
15. $\sin(2\pi\cdot40\cdot0.003) = \sin(0.24\pi) = \sin(43.2°) \approx 0.685$
