# D1 Vectors in 2D and 3D – Solutions

> Worksheet: [[D1 Vectors in 2D and 3D - Worksheet]] · Theory: [[D1 Vectors in 2D and 3D]] · Wrong? → [[Mistakes - Geometry and Vectors]]

## Level 1
1. $\mathbf a + \mathbf b = (3, 3, 1)$; $\;2\mathbf a - 3\mathbf b = (4 - 3,\ -2 - 12,\ 6 + 6) = (1, -14, 12)$
2. $\sqrt{9 + 16} = 5$; $\;\sqrt{1 + 4 + 4} = 3$
3. Length 5 → $\left(\tfrac35, 0, \tfrac45\right)$
4. $\vec{PQ} = (3, 4, 0)$; $d = 5$; midpoint $\left(\tfrac52, 4, 3\right)$

## Level 2
5. $s(1,1) + t(1,2) = (5, 7)$ → $s + t = 5$, $s + 2t = 7$ → $t = 2$, $s = 3$ → $(5, 7) = 3(1,1) + 2(1,2)$
6. No: $(2, 4, 6) = 2\cdot(1, 2, 3)$.
7. $\det\begin{pmatrix}1&0&1\\0&1&1\\1&1&0\end{pmatrix} = 1(0 - 1) - 0 + 1(0 - 1) = -2\neq0$ → independent.
8. $x^2 + 9 = 25\Rightarrow x = \pm4$
9. $A + \tfrac13(B - A) = (1, 2, 3)$

## Level 3
10. $\vec{E_1E_2} = (0, 30, 40)$, distance $\sqrt{900 + 1600} = 50\,\text{mm}$. $E_2$ is more **anterior** ($+y$) and more **superior** ($+z$), same left–right position.
11. $\mathbf P = 10(1,0) + 20(0,1) + 4(-1,0) = (6, 20)$ → mostly "up" ($+y$), slightly to the right.
12. $\lVert(10,2) - (4,10)\rVert = \lVert(6, -8)\rVert = 10\,\text{Hz}$. To A: $\lVert(-2, 2)\rVert = \sqrt8\approx2.8$; to B: $\lVert(4, -6)\rVert = \sqrt{52}\approx7.2$ → closer to A (a "nearest-neighbour decoder" would say A).
13. $\Delta = (20.8, -43.4, 15.3)$ → $\sqrt{432.64 + 1883.56 + 234.09} = \sqrt{2550.29}\approx50.5\,\text{mm}$
