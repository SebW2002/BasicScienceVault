# D4 Unit Circle Trigonometry – Solutions

> Worksheet: [[D4 Unit Circle Trigonometry - Worksheet]] · Theory: [[D4 Unit Circle Trigonometry]] · Wrong? → [[Mistakes - Geometry and Vectors]]

## Level 1
1. $\sin$: $0, \frac12, \frac{\sqrt2}2, \frac{\sqrt3}2, 1$; $\;\cos$: $1, \frac{\sqrt3}2, \frac{\sqrt2}2, \frac12, 0$
2. $\sin150° = \sin30° = \frac12$ (QII, +); $\;\cos210° = -\cos30° = -\frac{\sqrt3}2$ (QIII); $\;\tan300° = -\tan60° = -\sqrt3$ (QIV)
3. $-\frac{\sqrt2}2$; $\;\cos\frac{5\pi}3 = \cos(-\frac\pi3) = \frac12$; $\;\sin\frac{7\pi}6 = -\sin\frac\pi6 = -\frac12$
4. Quadrant IV

## Level 2
5. $\sin^2\theta = 1 - \frac9{25} = \frac{16}{25}$, QIV → $\sin\theta = -\frac45$; $\tan\theta = -\frac43$
6. Opposite $= 10\sin30° = 5$; adjacent $= 10\cos30° = 5\sqrt3$
7. $1 + \frac{\sin^2}{\cos^2} = \frac{\cos^2 + \sin^2}{\cos^2} = \frac1{\cos^2}$ ✓
8. $c^2 = 9 + 25 - 2\cdot3\cdot5\cdot\frac12 = 19\Rightarrow c = \sqrt{19}$

## Level 3
9. $(2\cdot\frac12,\ 2\cdot\frac{\sqrt3}2) = (1, \sqrt3)$
10. $r = \sqrt2$; point in QII → $\theta = 135° = \frac{3\pi}4$ (note: $\arctan\frac{1}{-1} = -45°$ would be wrong!)
11. $(0,-3)$: $r = 3$, $\theta = \frac{3\pi}2$ ($270°$). $\;(-2, 0)$: $r = 2$, $\theta = \pi$.

## Level 4
12. Unit vectors $(1, 0)$, $(0, 1)$, $(-1, 0)$ → mean $\left(0, \frac13\right)$ → $R = \frac13$, mean phase $\frac\pi2$.
13. $\left(\frac{\sqrt3}2, \frac12\right)$ and $\left(\frac{\sqrt3}2, -\frac12\right)$ → mean $\left(\frac{\sqrt3}2, 0\right)$ → mean phase $0$, $R = \frac{\sqrt3}2\approx0.87$ (strong locking).
14. Arithmetic: $180°$ – exactly the opposite direction! Circular: vectors at $\pm10°$ → mean phase $0°$ (with $R = \cos10°\approx0.98$).
15. $300°$: $\cos180° = -1$ → $5\,\text{Hz}$ (minimum). $180°$: $\cos60° = \frac12$ → $27.5\,\text{Hz}$.
16. QIII: $\theta = 180° + \arctan\frac34\approx180° + 36.87° = 216.87°$
