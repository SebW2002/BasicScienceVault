# A8 Solving Equations – Solutions

> Worksheet: [[A8 Solving Equations - Worksheet]] · Theory: [[A8 Solving Equations]] · Wrong? → [[Mistakes - Basics]]

## Level 1
1. $3x = 18 \Rightarrow x = 6$
2. $5x - 10 = 2x + 8 \Rightarrow 3x = 18 \Rightarrow x = 6$
3. $\dfrac{4x + 3x}{12} = 7 \Rightarrow 7x = 84 \Rightarrow x = 12$
4. $-2x > 6 \Rightarrow x < -3$ (sign flips!)

## Level 2
5. $(x - 2)(x - 3) = 0 \Rightarrow x \in \{2, 3\}$
6. $2x(x - 4) = 0 \Rightarrow x \in \{0, 4\}$
7. $(x + 5)(x - 1) = 0 \Rightarrow x \in \{1, -5\}$
8. $D = 4 - 20 = -16 < 0$ → no real solution (complex: $x = -1 \pm 2i$)
9. $x^2 - 2x = 0 \Rightarrow x(x-2) = 0 \Rightarrow x \in \{0, 2\}$
10. $x \in \{1, -4, \tfrac32\}$

## Level 3
11. Domain $x \neq \pm1$. $3(x+1) = 2(x-1) \Rightarrow 3x + 3 = 2x - 2 \Rightarrow x = -5$ ✓ (in domain)
12. $2x - 3 = 5 \Rightarrow x = 4$ or $2x - 3 = -5 \Rightarrow x = -1$
13. $u = x^2$: $u^2 - 5u + 4 = (u-1)(u-4) = 0$ → $x^2 = 1$ or $x^2 = 4$ → $x \in \{-2, -1, 1, 2\}$
14. $2x = \ln 7 \Rightarrow x = \tfrac12\ln 7$
15. $x + 1 = e^2 \Rightarrow x = e^2 - 1$

## Level 4
16. a) $C = \tau/R$; b) $V = E + I/g$; c) $\ln\frac{c_o}{c_i} = \frac{zFE}{RT} \Rightarrow \frac{c_o}{c_i} = e^{zFE/(RT)} \Rightarrow c_i = c_o\, e^{-zFE/(RT)}$
17. $20(1 - e^{-t/10}) = 10 \Rightarrow e^{-t/10} = \tfrac12 \Rightarrow -t/10 = \ln\tfrac12 = -\ln 2 \Rightarrow t = 10\ln2\,\text{ms}$ ($\approx 6.9\,\text{ms}$).
    $25\,\text{mV}$: $e^{-t/10} = 1 - 1.25 = -0.25 < 0$ – impossible, since $e^{(\cdot)} > 0$. The voltage approaches 20 mV but never exceeds it.
18. $0 = -(V + 70) + 15 \Rightarrow V = -55\,\text{mV}$
19. $t = -20\ln(1 - 25/30) = -20\ln\tfrac16 = 20\ln 6 \approx 20 \cdot 1.792 \approx 35.8\,\text{ms}$
