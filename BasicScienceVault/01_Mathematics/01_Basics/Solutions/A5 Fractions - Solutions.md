# A5 Fractions – Solutions

> Worksheet: [[A5 Fractions - Worksheet]] · Theory: [[A5 Fractions]] · Wrong? → [[Mistakes - Basics]]

## Level 1
1. $\dfrac{8 + 9}{12} = \dfrac{17}{12}$
2. $\dfrac{10 - 3}{12} = \dfrac{7}{12}$
3. $\dfrac{30}{45} = \dfrac23$
4. $\dfrac47 \cdot \dfrac{21}{2} = \dfrac{84}{14} = 6$
5. Numerator $\dfrac{3+2}{6} = \dfrac56$ → $\dfrac{5/6}{5/6} = 1$

## Level 2
6. $\dfrac{2}{2x} + \dfrac{1}{2x} = \dfrac{3}{2x}$
7. $\dfrac{a^2 + b^2}{ab}$
8. $\dfrac{(x+1) - (x-1)}{(x-1)(x+1)} = \dfrac{2}{x^2-1}$
9. $\dfrac{2x - (x-2)}{x(x-2)} = \dfrac{x+2}{x(x-2)}$
10. $\dfrac{x}{x+1}\cdot\dfrac{(x-1)(x+1)}{x^2} = \dfrac{x-1}{x}$ ($x \neq 0, -1$)
11. Multiply top and bottom by $x$: $\dfrac{x+1}{x-1}$

## Level 3
12. $f(c + K) = c \Rightarrow fK = c - fc \Rightarrow K = \dfrac{c(1-f)}{f}$
13. $\dfrac1R = \dfrac{R_2 + R_1}{R_1 R_2} \Rightarrow R = \dfrac{R_1R_2}{R_1 + R_2}$

## Level 4
14. a) $\dfrac{100\cdot100}{200} = 50\,\text{M}\Omega$
    b) $\dfrac1R = \dfrac1{60} + \dfrac2{60} + \dfrac3{60} = \dfrac{6}{60} = \dfrac1{10} \Rightarrow R = 10\,\text{M}\Omega$ (smaller than the smallest single resistance)
15. $c = K$: $\dfrac{K^2}{2K^2} = \dfrac12$; $\;c = 3K$: $\dfrac{9K^2}{10K^2} = \dfrac{9}{10}$; $\;c = K/2$: $\dfrac{K^2/4}{K^2/4 + K^2} = \dfrac{1/4}{5/4} = \dfrac15$
16. $R_1 = \dfrac{6}{2 + 6 + 2} = 0.6$. With $r_2 = 12$: $R_1 = \dfrac{6}{20} = 0.3$ – the response of neuron 1 is halved although its own input didn't change (normalisation by the neighbour).
