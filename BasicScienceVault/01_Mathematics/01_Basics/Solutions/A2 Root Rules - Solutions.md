# A2 Root Rules – Solutions

> Worksheet: [[A2 Root Rules - Worksheet]] · Theory: [[A2 Root Rules]] · Wrong? → [[Mistakes - Basics]]

## Level 1
1. $\sqrt{25 \cdot 2} = 5\sqrt2$
2. $\sqrt{4\cdot3} + \sqrt{9\cdot3} = 2\sqrt3 + 3\sqrt3 = 5\sqrt3$
3. $\sqrt{16} = 4$
4. $\sqrt[3]{27 \cdot 2} = 3\sqrt[3]{2}$
5. $x^{3/4}$ and $x^{-1/2}$

## Level 2
6. $\sqrt{x^6} = \sqrt{(x^3)^2} = \lvert x^3 \rvert = \lvert x \rvert^3$ (the absolute value is necessary, e.g. $x = -1$)
7. $\dfrac{6\sqrt3}{3} = 2\sqrt3$
8. $\dfrac{\sqrt5+2}{(\sqrt5-2)(\sqrt5+2)} = \dfrac{\sqrt5+2}{5-4} = \sqrt5+2$
9. Third binomial formula: $7 - 3 = 4$
10. $\sqrt{x \cdot x^{1/2}} = \sqrt{x^{3/2}} = x^{3/4}$
11. $\sqrt{9 \cdot 2 \cdot a^2 \cdot a \cdot b^2} = 3ab\sqrt{2a}$

## Level 3
12. Square: $x + 3 = 25 \Rightarrow x = 22$. Check: $\sqrt{25} = 5$ ✓
13. Square: $2x + 1 = x^2 - 2x + 1 \Rightarrow x^2 - 4x = 0 \Rightarrow x(x-4) = 0 \Rightarrow x \in \{0, 4\}$.
    Check $x = 0$: $\sqrt1 = 1$, but $0 - 1 = -1$ ✗ (false solution created by squaring).
    Check $x = 4$: $\sqrt9 = 3 = 4 - 1$ ✓ → **$x = 4$ only**.
14. a) $\text{SEM} = 12/\sqrt{36} = 12/6 = 2\,\text{Hz}$
    b) $12/\sqrt n = 1 \Rightarrow \sqrt n = 12 \Rightarrow n = 144$ trials (4× more trials for half the SEM).
15. a) $x = \sqrt{2 \cdot 0.5 \cdot 100} = \sqrt{100} = 10\,\mu\text{m}$
    b) $t = \dfrac{x^2}{2D} = \dfrac{400}{1} = 400\,\text{ms}$ (twice the distance → four times the time)
16. Squares: $9, 16, 25, 4$ → sum $54$, mean $13.5$ → $\text{RMS} = \sqrt{13.5} \approx 3.67\,\mu\text{V}$
