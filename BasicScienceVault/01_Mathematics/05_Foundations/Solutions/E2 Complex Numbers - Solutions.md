# E2 Complex Numbers – Solutions

> Worksheet: [[E2 Complex Numbers - Worksheet]] · Theory: [[E2 Complex Numbers]] · Wrong? → [[Mistakes - Foundations]]

## Level 1
1. $4 - 3i$
2. $6 - 4i + 3i - 2i^2 = 6 - i + 2 = 8 - i$
3. $-i$; $\;1$; $\;i^{10} = i^8\cdot i^2 = -1$
4. $\bar z = 3 + 4i$; $\lvert z\rvert = 5$
5. $\dfrac{(1 + 2i)(1 + i)}{(1 - i)(1 + i)} = \dfrac{1 + i + 2i + 2i^2}{2} = \dfrac{-1 + 3i}{2}$

## Level 2
6. $z^2 = -4\Rightarrow z = \pm2i$. $\;z = \frac{2\pm\sqrt{4 - 20}}{2} = \frac{2\pm4i}{2} = 1\pm2i$
7. $(a + bi)(a - bi) = a^2 - (bi)^2 = a^2 + b^2 = \lvert z\rvert^2$ ✓ (third binomial formula)

## Level 3
8. $1 + i = \sqrt2e^{i\pi/4}$; $\;-2 = 2e^{i\pi}$; $\;-3i = 3e^{-i\pi/2}$ (or $3e^{i3\pi/2}$)
9. $2(\cos\frac\pi3 + i\sin\frac\pi3) = 1 + i\sqrt3$; $\;e^{i\pi/2} = i$
10. $(\sqrt2e^{i\pi/4})^4 = 4e^{i\pi} = -4$
11. $e^{i\pi} = \cos\pi + i\sin\pi = -1 + 0i$ → $-1 + 1 = 0$ ✓

## Level 4
12. Amplitude $\lvert X\rvert = \sqrt{9 + 9} = 3\sqrt2$; power $18$; phase $\arg X = -\frac\pi4$ (point in quadrant IV).
13. $\frac12(1 + i)$ → $\left\lvert\frac12 + \frac12i\right\rvert = \sqrt{\frac14 + \frac14} = \frac{\sqrt2}2\approx0.71$
14. Real part $-1 < 0$ → decays (damped). Angular frequency $\omega = 2$ (per 10 ms) → period $T = \frac{2\pi}{\omega} = \pi$ time units $\approx 31\,\text{ms}$ (≈ 32 Hz – gamma range).
