# E1 Sets, Logic and Quantifiers – Solutions

> Worksheet: [[E1 Sets Logic and Quantifiers - Worksheet]] · Theory: [[E1 Sets Logic and Quantifiers]] · Wrong? → [[Mistakes - Foundations]]

## Level 1
1. $A\cup B = \{1,2,3,4,5\}$; $A\cap B = \{3,4\}$; $A\setminus B = \{1,2\}$; $B\setminus A = \{5\}$
2. $[-2, 5)$; $\;[-3, 3]$
3. a) false b) false (irrational) c) true ($\frac12$) d) true e) false – $\emptyset$ has no elements, $\{0\}$ has one.
4. $\{(a,1), (a,2), (b,1), (b,2)\}$
5. $\{\emptyset, \{1\}, \{2\}, \{1,2\}\}$; $2^5 = 32$

## Level 2
6. $A\cup B = \{1,2,3,4\}$, complement $\{5,6\}$. $A^c = \{4,5,6\}$, $B^c = \{1,2,5,6\}$, $A^c\cap B^c = \{5,6\}$ ✓
7. Both columns are T, F, T, T (for TT, TF, FT, FF) → identical: the contrapositive is equivalent.
8. $(p\wedge q)\Rightarrow p$: yes, tautology. $p\Rightarrow(p\wedge q)$: no – false when $p$ = T, $q$ = F.
9. a) sufficient ($x > 5\Rightarrow x > 2$) b) necessary (every $x > 5$ has $x > 2$, but $x = 3$ shows it's not sufficient)

## Level 3
10. $\exists x\in\mathbb R: x^2 < 0$ – false (the original is true).
11. $\forall x\in\mathbb R: x^2\neq-1$ – true in $\mathbb R$ (but not in $\mathbb C$!).
12. a) true (choose $y$ depending on $x$) b) false (one fixed $y$ can't equal $x + 1$ for all $x$)
13. "For every tolerance $\varepsilon$ there is an index $N$ from which on all sequence members are within $\varepsilon$ of $L$" – the definition of the **limit** of a sequence, $a_n\to L$.

## Level 4
14. $\lvert F\cup H\rvert = 50 + 40 - 15 = 75$; neither: $120 - 75 = 45$
15. "Every neuron has at least one stimulus for which it does not fire."
16. Contrapositive: "If new episodic memories are formed, the hippocampus is not lesioned." – equivalent ✅.
    Converse: "If no new episodic memories are formed, the hippocampus is lesioned." – **not** equivalent (there are other causes).
17. Necessary (without X no Y) but not sufficient (activating X alone doesn't produce Y).
