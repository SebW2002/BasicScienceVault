# Mistake Entry Template

Copy this row into the *My mistakes* table of the matching mistake log:
[[Mistakes - Basics]] · [[Mistakes - Analysis]] · [[Mistakes - Linear Algebra]] · [[Mistakes - Geometry and Vectors]] · [[Mistakes - Foundations]]

```markdown
| YYYY-MM-DD | ❌ wrong step | ✅ correct step | why it's wrong / quick test that catches it | [[Topic note]] |
```

## Good entries are …
- **Specific:** the exact step that went wrong, not "made a mistake with fractions".
- **Testable:** a quick number check (e.g. plug in $a = b = 1$) that would have exposed it.
- **Linked:** link the topic note so the mistake shows up in its backlinks.
- **Tagged (optional):** add `#mistake/sign`, `#mistake/rule`, `#mistake/careless`, `#mistake/concept` in the row to spot patterns via the tag pane.

## Review routine
1. Before each worksheet: skim the log of that field (2 min).
2. Weekly: re-do the tasks behind your last 5 entries without looking.
3. Before an exam: read all logs – mark entries you no longer make with ✔️.
